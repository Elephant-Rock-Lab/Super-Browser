### TASK-18-01: Tier-Based Safety Gate

**Source:** `clawdcursor/src/pipeline/safety/layer.ts`

Create `security/gate.py` — a pure function `evaluate(tool_name, args, target_label) → Decision`:
- **Allow** tier: read-only operations (observe, extract)
- **Confirm** tier: destructive operations (close_window, evaluate JS)
- **Block** tier: banned operations (specific key combos, known injection patterns)
- Input tier operations run freely but check target labels against confirm patterns

```python
# security/gate.py
class SafetyDecision:
    allow: bool
    tier: str  # "read" | "input" | "destructive" | "system"
    reason: str | None

def evaluate(tool: str, args: dict, target_label: str | None = None) -> SafetyDecision:
    ...
```

Wire into `facade.py` — every public method calls `evaluate()` before executing. This systematically prevents the silent failure class of bugs.

**Tests:** +15 (tier classification, label patterns, compound tool mapping)
**Estimated effort:** 3 hours

### TASK-18-02: Deterministic Router

**Source:** `clawdcursor/src/pipeline/router/router.ts`

Create `agent/router.py` — intercepts known patterns without LLM:

```python
class DeterministicRouter:
    def route(self, instruction: str) -> RouteResult:
        # "go to <url>" → navigate directly
        # "click <selector>" → click directly  
        # "extract <selector>" → extract directly
        # "scroll down" → scroll directly
        # Everything else → fallback to LLM
```

Benefits:
- **Cost savings:** Simple navigation/interaction skips LLM call entirely
- **Speed:** 10ms router vs 500ms LLM call
- **Reliability:** No LLM hallucination for mechanical tasks

Wire into `facade.act()` — try router first, fall back to LLM agent loop only when needed.

**Tests:** +10 (URL patterns, selector patterns, compound rejection, fallback)
**Estimated effort:** 3 hours

### TASK-18-05: ActionResult.raise_for_error() + ok_or_raise()

**Source:** UX report recommendation #18, #19

```python
class ActionResult:
    def raise_for_error(self) -> None:
        """Raise if not ok — like requests.Response.raise_for_status()."""
        if not self.ok:
            raise ActionError(...)
    
    def ok_or_raise(self) -> Any:
        """Return data if ok, raise if not."""
        if not self.ok:
            raise ActionError(...)
        return self.data
```
