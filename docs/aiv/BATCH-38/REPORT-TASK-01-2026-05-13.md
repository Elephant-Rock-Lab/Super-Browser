## Design Decisions

1. **Single IIFE** — All 5 surfaces in one payload (as specified), avoiding multiple small injections.
2. **Voice pool (14 entries)** — Realistic TTS voice names from Chrome/Safari/Windows; PRNG selects 2–4 per profile.
3. **`:link` fallback** — For `:visited` normalisation, reads `:link` computed style as the canonical unvisited value, catching both CSS-rule and inline-style differences.
4. **Plain-object rect return** — `getBoundingClientRect` returns a plain JS object (not a DOMRect) with jitter applied, which is sufficient for fingerprint noise while remaining API-compatible for most consumers.
5. **inject_order=50** — Runs last among ejectors so rect jitter and style overrides layer on top of canvas/WebRTC/timing protections.

## Payload Size

Default config (`seed="default"`, `profile_id=""`): **~4.6 KB** UTF-8.
