## Architecture

### Dual-Mechanism Routing

```
BrowserFetch.fetch(url, init?)
│
├─ Simple GET? ── Mechanism A ── Network.loadNetworkResource
│   (no headers/body, method=GET or omitted)       │
│                                                   ▼
│                                          IO.StreamHandle
│                                          drain via IO.read (64KB chunks)
│                                          IO.close (best-effort)
│
└─ Otherwise ──── Mechanism B ── Runtime.callFunctionOn
                    (POST, custom headers, body)      │
                                                     ▼
                                         In-page fetch(url, init)
                                         → {status, headers, bodyB64}
                                         base64-decode body
```

### Scratch Frame Lifecycle

```mermaid
graph LR
    A[First fetch call] --> B[ensure_scratch_frame]
    B --> C[Target.createTarget<br/>about:blank]
    C --> D[Target.attachToTarget<br/>flatten=true]
    D --> E[Page.getFrameTree<br/>→ frameId]
    E --> F[Cache _ScratchFrame<br/>{targetId, sessionId, frameId}]
    F --> G[Reuse on all<br/>subsequent fetches]
    G --> H[close<br/>Target.closeTarget]
```

### Path Selection Logic

```python
is_simple_get = (
    init is None
    or (
        init.get("method", "GET").upper() == "GET"
        and "headers" not in init
        and "body" not in init
    )
)
```

## Session Integration

`BrowserSession.fetch` property lazily creates a `BrowserFetch` instance on the first `new_page()` call:

```python
session = BrowserSession()
await session.start()
page = await session.new_page()
# session.fetch is now a BrowserFetch backed by the CDP bridge
resp = await session.fetch.fetch("https://api.example.com/data")
```

The `fetch` property raises `RuntimeError` if no page has been opened yet (no CDP bridge available).

## Key Design Decisions

1. **CDP helpers live in `fetch.py`**, not `cdp.py` — CDPBridge.send() already handles arbitrary methods; all fetch-specific logic stays encapsulated.
2. **`asyncio.Lock`** protects scratch frame creation from concurrent races (same pattern as Mochi's `scratchFramePromise`).
3. **`documentObjectId` cached** — `DOM.getDocument` + `DOM.resolveNode` run once per scratch frame, not per fetch call.
4. **`CdpFetchError`** — dedicated exception class for all CDP-routed fetch failures, with clear error messages.
5. **`_flatten_headers`** — normalises CDP header maps (which can be `str` or `list[str]`) to `dict[str, str]`.
