## Design Decisions

1. **GPU vendor matching** — Profile stores full vendor string (e.g. `"NVIDIA Corporation"`) while the matrix WebGL value is a composite (e.g. `"Google Inc. (NVIDIA)"`). The check extracts the primary token (`split()[0]`) and performs case-insensitive substring matching. This handles the impedance mismatch between profile schema and runtime values.

2. **Fonts_OS_Match heuristic** — Maintains known platform-specific font sets for macOS, Windows, and Linux. Flags cross-contamination (e.g. SF Pro Display appearing on a Linux profile). Passes by default if OS is unknown.

3. **Timezone_Locale mapping** — Extracts region code from locale (`en-US` → `US`), maps to known timezone prefixes. Unknown regions pass by default to avoid false positives.

4. **Score formula** — `score = (passed / total) × 100`. Integer arithmetic; all 8 checks weighted equally.
