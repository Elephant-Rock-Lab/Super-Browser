## Architecture

```
click/fill/scroll()
  └─► _execute_with_stale_recovery(action, target, desc, t1, t2, t3)
        ├─► _cascade()                    ← first attempt
        │     └─► if ok → return (zero overhead on happy path)
        ├─► StaleRefDetector.is_stale()   ← check error signature
        │     └─► if NOT stale → return original failure
        ├─► capture_ax_snapshot()         ← refresh refs
        ├─► _cascade()                    ← retry attempt
        │     └─► if ok → return success
        └─► set failure_category=STALE_REF
            + populate next_actions        ← structured recovery guidance
```
