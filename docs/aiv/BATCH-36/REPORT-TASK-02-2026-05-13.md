## AudioEjector Design

### Class signature
```python
class AudioEjector:
    __slots__ = ("_inject_order",)
    def __init__(self, inject_order: int = 20) -> None: ...
    def generate(self, config: EjectorConfig) -> EjectorResult: ...
```

### JS Payload — Overridden APIs

The IIFE injects noise into **5 Web Audio API touchpoints**:

| # | API Override | Noise Target |
|---|-------------|--------------|
| 1 | `AudioContext.prototype.createBuffer` | Buffer channel data (Float32) |
| 2 | `AnalyserNode.prototype.getFloatFrequencyData` | Frequency domain data |
| 3 | `AudioBuffer.prototype.getChannelData` | All channel data reads |
| 4 | `OfflineAudioContext.prototype.createBuffer` | Offline rendering buffers |
| 5 | `AudioBufferSourceNode.prototype.buffer` (setter) | Source buffer assignment |

### Noise model
- **PRNG:** Mulberry32, seeded from `SHA-256(profile_id + ':' + seed)` → first 4 bytes as u32 LE
- **Amplitude:** `±audio_noise_magnitude` (default `0.0001`), applied per-sample as `(PRNG() * 2 - 1) * MAG`
- **Type:** Float32 additive perturbation (no clamping — audio data is not integer-bounded)

### Determinism
Same `(profile_id, seed)` pair → same JS seed integer → identical payload string.
