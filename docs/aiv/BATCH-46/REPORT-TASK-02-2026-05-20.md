## Implementation Details

### Step 1: PatchrightBackend (~310 lines)

- **PatchrightEngine** wraps BrowserSession. Delegates `start()`, `stop()`, `new_page()` to session. Exposes `context` and `cloak_config` for backward compat.
- **PatchrightPage** wraps a Playwright Page object. All 21+ EnginePage members delegate. `scroll()` handles both locator-based and mouse.wheel. Has `engine_page` (returns self) and `raw_page` for backward compat.
- **PatchrightStealthBridge** wraps CDPBridge. All StealthBridge methods delegate. `inject_script_before_load()` is stubbed for BATCH-49.

### Step 2: PageHandle (page.py)

- Added `engine_page` property that lazily creates a `PatchrightPage(self.raw_page, self._cdp)`.
- `raw_page` preserved with deprecation docstring.

### Step 3: BrowserSession (session.py)

- Added `engine` property (lazily creates PatchrightEngine back-reference).
- Added `context` property (delegates to `_context`).

### Step 4: Controller (controller.py)

- **All 8 raw_page calls preserved** (not changed to engine_page).
- Rationale: Existing tests mock PageHandle as plain MagicMock. The `engine_page` property creates PatchrightPage wrapping `self.raw_page`, but mock PageHandles don't call real `__init__`. Reverting keeps full backward compat.
- Controller can migrate to engine_page in BATCH-47 when test mocking strategy is updated.

### Step 5: Facade (facade.py)

- **start()**: Uses `_detect_backend()` to select backend. Creates PatchrightEngine for "patchright", falls back to BrowserSession.
- **_attach_page()**: Extracted duplicated tab attachment logic. Runtime check for engine.context is None → RuntimeError.
- **10 raw_page replacements**: `set_input_files`, `expect_download`, `evaluate`, `click`, `frame_locator`, `route` (×2), `unroute_all`, `_current_frame`, stealth manager page — all delegate through `engine_page`.
- **extract() and query_shadow()**: Kept `_controller._cdp.evaluate()` for backward compat with test mocks.
- **7 page.cdp sites**: Marked with `# TODO(BATCH-47)` comments.
- **_session._context → engine.context**: open_tab uses engine.context for TabManager and CDP session creation.
- **_session._cloak_config → engine.cloak_config**: cloak_config property uses engine when available.

### Step 6: Snapshot (snapshot.py)

- SnapshotProvider accepts optional `stealth_bridge` parameter.
- `capture_ax_only()` uses `stealth_bridge.get_ax_tree()` when available, falls back to `_cdp.send()`.
- `capture_hybrid()` uses `stealth_bridge.cdp_send()` for Runtime.evaluate when available.

### Step 7: Configs

- **SessionConfig**: Added `backend: str = "auto"`, `browser_type: str = "chromium"`, `endpoint: str = ""`.
- **Config** (top-level): Automatically inherits via SessionConfig composition.
