## Design Decisions

1. **`EngineCapabilities` is mutable dataclass** (not frozen) — matches `SessionConfig` compatibility pattern
2. **`_detect_backend` is module-level function** — allows easy mocking in TASK-02
3. **`cdp_send` returns `CDPResult`** — seamless integration with existing CDPBridge
4. **`scroll(direction, amount, target=None)`** — dual-mode: element scroll when target provided, viewport scroll when None
5. **`stealth_bridge` is Optional property** — backends without CDP/BiDi return None gracefully
