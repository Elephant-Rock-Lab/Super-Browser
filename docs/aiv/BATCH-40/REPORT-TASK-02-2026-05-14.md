## Design Decisions

### PageFingerprint (frozen=True)
Immutable by design — represents a point-in-time snapshot. Uses the same 4 lightweight signals as the agent loop's `_compute_page_fingerprint`: `url`, `title`, `node_count`, `interactive_count`. No full DOM hash.

### Detection Order in compute_page_change()
1. **URL change** → `"navigation"` (highest signal)
2. **node_count or interactive_count change** → `"mutation"`
3. **Otherwise** → `"unchanged"`

This ordering is intentional: a URL change is always a navigation regardless of whether node counts also changed.

### Backward Compatibility
- `page_change_summary` field remains `Optional` with `None` default
- `from_dict()` handles old dicts missing the key gracefully (via `.get()`)
- No existing `ActionResult` field positions or types were altered

## What TASK-03 Needs

The controller (`interaction/controller.py`) should:
1. Capture a `PageFingerprint` **before** `_cascade()` starts
2. Capture a `PageFingerprint` **after** `_cascade()` completes
3. Call `compute_page_change(before, after, artifact_hint=...)` and assign to `ActionResult.page_change_summary`

The agent loop (`agent/loop.py`) should:
- Read `result.page_change_summary.change_type` to skip wasteful re-snapshots when `"unchanged"`
- Branch on `result_category` for structured decision-making
