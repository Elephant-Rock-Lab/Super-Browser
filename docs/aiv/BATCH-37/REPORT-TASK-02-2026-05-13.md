## Implementation Details

### 1. TimingEjector (`timing.py`)

**Class structure** — follows the established `CanvasEjector` / `AudioEjector` pattern:
- `_seed_to_js_number()` — SHA-256 → u32 seed derivation (identical to canvas/audio)
- `_build_js_payload()` — f-string IIFE builder
- `TimingEjector.__init__(inject_order=40)` + `generate(config) -> EjectorResult`

**JavaScript payload does four things:**

| Override | Mechanism | Perturbation |
|----------|-----------|--------------|
| `performance.now()` | Floors to `timing_precision_ms`, adds ±0.1ms PRNG jitter | Defeats sub-ms timing fingerprinting |
| `performance.timeOrigin` | `Object.defineProperty` with ±100ms offset | Shifts origin epoch |
| `Math.PI`, `Math.E`, `Math.SQRT2`, `Math.LOG2E`, `Math.LN10` | `Object.defineProperty` with ±1e-15 noise | Defeats Math-constant fingerprinting |
| Inline mulberry32 PRNG | Same `0x6D2B79F5` pattern as canvas/audio | Deterministic per seed |

**Inject order:** `40` (after canvas=10, audio=20, webrtc=30).
