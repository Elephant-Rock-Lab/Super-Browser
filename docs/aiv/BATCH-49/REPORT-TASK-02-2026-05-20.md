## Design Decisions

1. **CDPInjector as thin wrapper**: Does NOT re-implement Fetch interception. Creates `InjectDelivery` on `inject_before_load` and exposes it via `.delivery` property for StealthManager to call `install()` with proper bridge context.

2. **PageScriptInjector.set_page()**: Added explicit `set_page()` method since the injector may receive a bridge that isn't the page object. Falls back to bridge if no page is set.

3. **BiDiInjector timing = BOTH**: As decided in Blueprint v1.1 review (CHK-12), BiDi can theoretically inject both before and after, so `BOTH` is the neutral choice pending implementation.

4. **select_injector precedence**: CDP > BiDi > PageScript, matching the capability-driven selection rule in the Authority Rules.
