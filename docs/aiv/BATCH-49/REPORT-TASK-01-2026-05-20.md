## Design Decisions

1. **`stealth_bridge` keyword-only in InjectDelivery**: Preserved backward compat with existing positional calls like `install(cdp, page)` by making `stealth_bridge` keyword-only (`*` separator).

2. **Duck typing via `_send()` helpers**: Each module has a thin `_send()` that checks for `.cdp_send()` first (StealthBridge), then falls back to `.send()` (CDPBridge). Zero behavioral change.

3. **Raw session access**: For Fetch event subscription, `InjectDelivery._get_raw_session()` traverses `stealth_bridge._cdp._session` (PatchrightStealthBridge wraps CDPBridge which has `_session`). Falls back to `cdp_bridge._session` for backward compat.

4. **`_FakeResult` replacement**: Replaced class definition with `type("_Result", ...)` call to avoid polluting the class namespace while keeping the same behavior.

5. **No behavioral change**: Same CDP commands flow, same injection timing, same payloads. The StealthBridge is a delegation layer, not a reimplementation.
