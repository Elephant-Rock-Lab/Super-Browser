## Algorithm Details

### Mouse Trajectory (`mouse.py`)
1. **Target sampling**: If `box` provided, click point sampled via truncated Gaussian (σ = dim/4) toward box center; else uses `to` directly.
2. **Bézier control points**: P1 at 30% and P2 at 70% along P0→P3, offset perpendicular by `tremor × distance × hand_bias × random_sign`.
3. **Overshoot**: 10% probability — first sub-curve overshoots by 1.05-1.15× D, second corrective curve returns (75/25 time split).
4. **Sampling**: N = ceil(MT × 60) points at 60Hz.
5. **Jitter**: AR-1 process with α = exp(-dt/30ms), σ = tremor × 1.0. Endpoints anchored exactly.

### Keyboard (`keyboard.py`)
1. **Press duration**: Gaussian(80, 25)ms, clamped [20, 200].
2. **Inter-key delays**: Lognormal digraph model (same-hand μ=4.7, σ=0.35; cross-hand μ=4.4, σ=0.30; after-space μ=4.9, σ=0.40; after-punct 1.3× same-hand).
3. **WPM scaling**: `scale = target_mean / 110`, where `target_mean = 60000 / (wpm × 5)`, clamped [0.25, 4.0].
4. **Mistakes**: Adjacent QWERTY key → 200-500ms pause → Backspace → 100-300ms pause → correct key.

### Scroll (`scroll.py`)
1. **Inertial model**: v(t) = v₀·exp(-t/τ), τ = 350ms. Initial velocity derived from distance and time budget.
2. **Per-frame integration**: Average velocity over frame interval, capped at 100px.
3. **Jitter**: Multiplicative Gaussian (σ=0.05) on velocity per frame.
4. **Stepped mode**: Rounds each frame's deltaY to nearest 100px notch.

## Architecture Notes

- **No circular imports**: Dependency chain is strictly `types ← bezier ← mouse`, `types ← gauss ← keyboard/scroll`, `prng` used by all synthesizers.
- **PRNG seeding convention**: All modules use `prng_for(category, seed)` with `"behavioral:{category}:{seed}"` as the profile_id, ensuring cross-module isolation.
- **Hand bias**: Mouse trajectory bends are biased by `hand` parameter — right-hand users get slight clockwise bias, left-hand users the opposite.
