## Architecture

### Seed Generation
Each action generates a unique deterministic seed:
```
f"{session_seed}:{action_type}:{selector}:{timestamp_ns}"
```
This ensures reproducibility when `session_seed` is set, while remaining non-deterministic in production (default `session_seed=""`).

### Click Flow (`_patchright_click`)
```
resolve element → bounding_box()
  → BehaviorProfile from config
  → synthesize_mouse_trajectory(from=_last_cursor, to=center, box, profile, seed)
  → _dispatch_trajectory(page, events)  [move, move, ..., move → down → up]
  → update _last_cursor
```

### Type Flow (`_patchright_type`)
```
click(selector) → random_pause
  → synthesize_keystrokes(text, profile, seed, mistake_rate)
  → _dispatch_keystrokes(page, events)  [keydown → (keyup implicit) → ...]
```

### Scroll Flow (`_patchright_scroll`)
```
synthesize_scroll(from_pos=0, to_pos=scroll_step_px*amount, profile, seed)
  → _dispatch_scroll(page, events)  [wheel(dx, dy), ...]
```

### Dispatch Helpers
Three standalone async functions for testability:
- `_dispatch_trajectory(page, events)` — paces with `asyncio.sleep(t_ms/1000)`, calls `page.mouse.move/down/up`
- `_dispatch_keystrokes(page, events)` — paces similarly, calls `page.keyboard.press/type`
- `_dispatch_scroll(page, events)` — paces similarly, calls `page.mouse.wheel`
