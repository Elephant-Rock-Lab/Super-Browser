## BATCH-28 — Human Behavior & Fingerprint Scoring

**Goal:** Add human behavior simulation layer and fingerprint scoring that works with both CloakBrowser and Patchright backends. When CloakBrowser is active, use its `humanize=True`. When using Patchright, use our own behavioral simulation. Add a fingerprint scoring utility that tests against public detection APIs.

### TASK-01: BATCH-28/TASK-01 — Human Behavior Adapter
- **Priority:** Critical
- **Description:** Create a HumanBehaviorAdapter that abstracts human simulation across backends. When CloakBrowser is active, delegate to its humanize. When using Patchright, provide basic behavioral simulation (random delays, mouse jitter, typing cadence).
- **Files in scope:**
  - `src/super_browser/stealth/human.py` (NEW)
  - `src/super_browser/stealth/human_config.py` (NEW)
  - `src/super_browser/browser/cloak_backend.py` (MODIFY — wire humanize)
- **Depends on:** BATCH-27
- **Tests:** 5 unit tests
- **Estimated effort:** 1.5 days

- **Priority:** High
- **Description:** Create a fingerprint scoring tool that runs the browser against public detection sites (FingerprintJS, bot.sannysoft.com, nowsecure.nl) and produces a numeric score. Works with both backends.
- **Files in scope:**
  - `src/super_browser/stealth/fingerprint_scanner.py` (NEW)
  - `src/super_browser/stealth/scoring.py` (NEW)
- **Depends on:** BATCH-27
