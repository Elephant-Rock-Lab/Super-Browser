
## BATCH-22 — Event Bus & Plugin Hooks

**Goal:** Create an event bus and lifecycle hook system that allows users to extend Super Browser with before/after action hooks, custom error handlers, and registered plugins.

### Task Breakdown

#### TASK-01: BATCH-22/TASK-01 — Event Bus Core
- **Priority:** Critical
- **Description:** Create the synchronous + async event bus (`EventBus`) with typed events, subscriber registration, event emission, and error isolation (one failing handler must not crash the bus).
- **Files in scope:**
  - `src/super_browser/events/__init__.py` (NEW)
  - `src/super_browser/events/bus.py` (NEW)
  - `src/super_browser/events/types.py` (NEW)
- **Depends on:** None
- **Estimated effort:** 1 day
- **Required Tests:**
  | Test ID | Type | Behavior Verified | Failure Mode | Falsified By | Pass Criteria |
  |:--------|:-----|:------------------|:-------------|:-------------|:--------------|
  | TEST-22-01-01 | unit | EventBus registers and calls sync handler | Handler never called on emit | Remove handler registration call | handler.call_count == 1 |
  | TEST-22-01-02 | unit | EventBus registers and calls async handler | Async handler never awaited | Change `await` to fire-and-forget | await result matches expected |
  | TEST-22-01-03 | unit | One failing handler does not block others | Subsequent handlers skipped | Remove try/except isolation | all handlers called, error logged |
  | TEST-22-01-04 | unit | Unsubscribe stops handler from being called | Handler still called after unsub | Skip removal from handler list | handler.call_count == 0 after unsub |
  | TEST-22-01-05 | unit | Typed events only reach matching subscribers | Wrong event type delivered | Remove event type check in dispatch | only matching handler called |
- **Acceptance Criteria:**
  - AC-01-01: EventBus.emit() calls all registered handlers for that event type
  - AC-01-02: Handler errors are caught, logged, and do not propagate
  - AC-01-03: Handlers can be unsubscribed
  - AC-01-04: Both sync and async handlers supported
- **Traceability:**
  - AC-01-01 → TEST-22-01-01, TEST-22-01-02
  - AC-01-02 → TEST-22-01-03
  - AC-01-03 → TEST-22-01-04
  - AC-01-04 → TEST-22-01-02

#### TASK-02: BATCH-22/TASK-02 — Lifecycle Hooks Integration
- **Priority:** High
- **Description:** Wire lifecycle hooks into the SuperBrowser facade and agent loop. Emit events for: `before_navigate`, `after_navigate`, `before_action`, `after_action`, `on_error`, `on_loop_detected`, `on_budget_alert`. Add the `@hook` decorator for user-facing registration.
- **Files in scope:**
  - `src/super_browser/agent/facade.py` (MODIFY)
  - `src/super_browser/agent/loop.py` (MODIFY)
  - `src/super_browser/plugins/__init__.py` (NEW)
  - `src/super_browser/plugins/hooks.py` (NEW)
  - `src/super_browser/plugins/decorators.py` (NEW)
- **Depends on:** TASK-01
- **Estimated effort:** 1 day
- **Required Tests:**
  | Test ID | Type | Behavior Verified | Failure Mode | Falsified By | Pass Criteria |
  |:--------|:-----|:------------------|:-------------|:-------------|:--------------|
  | TEST-22-02-01 | unit | @hook("before_navigate") fires on navigate | Hook not called | Remove emit() call in facade | hook called with url in context |
  | TEST-22-02-02 | unit | @hook("on_error") fires on action failure | Error event not emitted | Skip emit in error handler | hook called with error details |
  | TEST-22-02-03 | unit | @hook("on_loop_detected") fires when loop guard triggers | Event not emitted on loop | Remove emit from loop_detector | hook called with nudge details |
  | TEST-22-02-04 | unit | Multiple hooks on same event all fire | Only first hook called | Use list append instead of overwrite | all hooks called in order |
  | TEST-22-02-05 | integration | Hook can modify navigate URL | URL not mutable | Pass context by value instead of ref | final URL == modified URL |
- **Acceptance Criteria:**
  - AC-02-01: `@hook("before_navigate")` fires before every navigate call
  - AC-02-02: `@hook("on_error")` fires on every action failure
  - AC-02-03: Hooks can be registered via decorator or `sb.on()`
  - AC-02-04: No performance regression (emit adds <1ms per action)
- **Traceability:**
  - AC-02-01 → TEST-22-02-01
  - AC-02-02 → TEST-22-02-02
  - AC-02-03 → TEST-22-02-04
  - AC-02-04 → TEST-22-02-05

### Batch-Level Acceptance Criteria
- BAC-01: EventBus works with sync and async handlers
- BAC-02: All 7 lifecycle hooks emit events
- BAC-03: `@hook()` decorator provides clean user API
- BAC-04: CHANGELOG.md updated
- BAC-05: All documents archived under /docs/aiv/BATCH-22/

### Hard Boundaries
- HB-22-01: EventBus.emit() must never raise — handler errors must be caught and logged
- HB-22-02: Hook registration must not require subclassing SuperBrowser
- HB-22-03: Each lifecycle event must include a typed context dict (not bare **kwargs)

## BATCH-23 — Session Recording & Replay

**Goal:** Record every browser action with before/after screenshots and DOM snapshots, save recordings as JSON, and support replay for debugging and audit.

### Task Breakdown

#### TASK-01: BATCH-23/TASK-01 — Recording Engine
- **Priority:** Critical
- **Description:** Create `SessionRecorder` that hooks into the event bus to capture: every navigate, click, fill, extract, scroll, and error. Each record includes: timestamp, action name, parameters, before/after screenshot (base64), page URL, page title, and any error details.
- **Files in scope:**
  - `src/super_browser/recording/__init__.py` (NEW)
  - `src/super_browser/recording/recorder.py` (NEW)
  - `src/super_browser/recording/types.py` (NEW)
- **Depends on:** BATCH-22 (event bus)
- **Estimated effort:** 1 day
- **Required Tests:**
  | Test ID | Type | Behavior Verified | Failure Mode | Falsified By | Pass Criteria |
  |:--------|:-----|:------------------|:-------------|:-------------|:--------------|
  | TEST-23-01-01 | unit | Recorder captures navigate event | Navigate events ignored | Skip event subscription | records[0].action == "navigate" |
  | TEST-23-01-02 | unit | Recorder captures click event with selector | Selector missing from record | Don't store params | record.params["selector"] == "#btn" |
  | TEST-23-01-03 | unit | Recorder captures error events | Errors not recorded | Only subscribe to success events | record.error is not None |
  | TEST-23-01-04 | unit | Recorder respects max_screenshots limit | Memory grows unbounded | Remove size limit check | len(records) <= max_records |
  | TEST-23-01-05 | unit | Recording.export() produces valid JSON | Export returns None | Return dict instead of JSON string | json.loads(export()) succeeds |
  | TEST-23-01-06 | unit | Recording includes timestamps | Timestamps are 0 | Don't call time.monotonic | all timestamps > 0 |

#### TASK-02: BATCH-23/TASK-02 — Persistence & Export
- **Priority:** High
- **Description:** Add save/load for recordings (JSON and HTML report). JSON format for programmatic replay, HTML for human audit. Include recording metadata: session ID, start/end time, total actions, error count.
- **Files in scope:**
  - `src/super_browser/recording/persistence.py` (NEW)
  - `src/super_browser/recording/report.py` (NEW)
- **Depends on:** TASK-01
- **Estimated effort:** 0.5 day
- **Required Tests:**
  | Test ID | Type | Behavior Verified | Failure Mode | Falsified By | Pass Criteria |
  |:--------|:-----|:------------------|:-------------|:-------------|:--------------|
  | TEST-23-02-01 | unit | save() writes JSON file | File not created | Skip file write | os.path.exists(path) |
  | TEST-23-02-02 | unit | load() reconstructs recording | Fields lost during serialization | Don't deserialize params | loaded.actions == original.actions |
  | TEST-23-02-03 | unit | export_html() produces valid HTML | Output is empty | Return empty string | "<html>" in html |
  | TEST-23-02-04 | unit | Metadata includes action_count | Count is 0 | Don't count actions | metadata["action_count"] == len(actions) |

#### TASK-03: BATCH-23/TASK-03 — Replay Engine
- **Priority:** High
- **Description:** Create `RecordingReplayer` that replays a saved recording against a live browser session. Replays each action in sequence with configurable delays. Compares results (success/failure) against the original recording.
- **Files in scope:**
  - `src/super_browser/recording/replayer.py` (NEW)
  - `src/super_browser/agent/facade.py` (MODIFY — add `replay()` method)
- **Depends on:** TASK-01, TASK-02
- **Estimated effort:** 1 day
- **Required Tests:**
  | Test ID | Type | Behavior Verified | Failure Mode | Falsified By | Pass Criteria |
  |:--------|:-----|:------------------|:-------------|:-------------|:--------------|
  | TEST-23-03-01 | unit | Replayer replays navigate actions | Navigate skipped | Skip action type dispatch | page.url == recorded_url |
  | TEST-23-03-02 | unit | Replayer replays click actions | Click not executed | Skip click in dispatch | click called on correct selector |
  | TEST-23-03-03 | unit | Replayer replays fill actions | Fill not executed | Skip fill in dispatch | fill called with correct value |
  | TEST-23-03-04 | unit | Replayer reports mismatches | Mismatch not detected | Compare None instead of result | report.mismatches is populated |

### Batch-Level Acceptance Criteria
- BAC-01: SessionRecorder captures all 7 action types + errors
- BAC-02: Recordings can be saved as JSON and HTML
- BAC-03: Replayer replays recordings with mismatch detection
- BAC-04: SuperBrowser.recording attribute provides recorder access
- BAC-05: CHANGELOG.md updated
- BAC-06: All documents archived under /docs/aiv/BATCH-23/

### Hard Boundaries

- HB-23-02: Screenshot capture failures must not block the action (log and continue)
- HB-23-03: Recording JSON format must be versioned (schema_version field)

## BATCH-25 — Agent Memory

**Goal:** Give the agent cross-session memory so it remembers successful action sequences, working selectors, and user preferences per domain.

### Task Breakdown

#### TASK-01: BATCH-25/TASK-01 — Memory Store
- **Priority:** Critical
- **Description:** Create the memory store with per-domain persistence. Store types: action sequences (ordered list of actions that completed a task), selector maps (CSS selectors that worked for specific elements), and preferences (key-value pairs). Storage backend: JSON files in `~/.config/super-browser/memory/`.
- **Files in scope:**
  - `src/super_browser/memory/__init__.py` (NEW)
  - `src/super_browser/memory/store.py` (NEW)
  - `src/super_browser/memory/types.py` (NEW)
- **Depends on:** None
- **Estimated effort:** 1.5 days
- **Required Tests:**
  | Test ID | Type | Behavior Verified | Failure Mode | Falsified By | Pass Criteria |
  |:--------|:-----|:------------------|:-------------|:-------------|:--------------|
  | TEST-25-01-01 | unit | store.save() writes domain file | File not written | Skip file write | os.path.exists(domain_path) |
  | TEST-25-01-02 | unit | store.load() reads domain file | Returns empty store | Don't read file | loaded.actions == saved.actions |
  | TEST-25-01-03 | unit | store.get_selectors() returns working selectors | Returns empty dict | Don't store selectors | "login_button" in selectors |
  | TEST-25-01-04 | unit | store.prune() removes entries older than TTL | Stale entries remain | Remove TTL check | len(store) < before |
  | TEST-25-01-05 | unit | Corrupted JSON file is handled gracefully | Crash on load | Remove try/except | empty store returned, error logged |
  | TEST-25-01-06 | unit | Memory entries have timestamps | Timestamps missing | Don't set timestamp | all entries have created_at > 0 |

#### TASK-02: BATCH-25/TASK-02 — Memory-Aware Agent Loop
- **Priority:** High
- **Description:** Wire memory into the agent loop. On task start: load domain memory and inject successful sequences as context in the LLM prompt. On task success: save the action sequence. On selector success: save the selector map. On task failure: don't save.
- **Files in scope:**

- **Depends on:** TASK-01
- **Estimated effort:** 1 day
- **Required Tests:**

  | TEST-25-02-02 | unit | Failed task does not save action sequence | Failed sequence saved | Remove failure check | store has no new entry |
  | TEST-25-02-03 | unit | Memory context injected into LLM prompt | Prompt unchanged | Skip memory injection | "Previous successful" in prompt |
  | TEST-25-02-04 | unit | Working selector saved to selector map | Selector not saved | Skip selector recording | store.selectors has entry |
