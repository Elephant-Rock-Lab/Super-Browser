## Design Decisions

- **Opt-in**: `enable_memory()` must be called explicitly; `_memory_store` starts as None (HB-25-01)
- **Save only on success**: `_save_to_memory()` is called only when `completion_reason == "success"`
- **Context injection**: Memory context is appended as advisory text block in the prompt, not as commands
- **URL extraction**: Domain is extracted from the current page URL via `urlparse`
