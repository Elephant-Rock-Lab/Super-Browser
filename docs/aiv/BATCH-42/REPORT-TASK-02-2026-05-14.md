## Design Decisions

1. **Pure data layer** — `BrowserJob` and `QASmoke` compile declarative step dicts into `CompiledStep` lists. No browser calls, no controller imports. Execution is entirely the caller's responsibility.

2. **`CompiledStep`** is a frozen dataclass with `action`, `params`, and `description`. This gives callers a clean, typed contract to dispatch against.

3. **Validation at construction** — `BrowserJob._validate()` runs on `__init__`, catching unknown actions and missing keys before any compilation attempt.

4. **`description` handling** — If a step dict includes `"description"`, it's promoted to `CompiledStep.description` and removed from `params`. Otherwise a default `"Execute {action}"` is used.

5. **QASmoke** is parameterized with `url`, `assert_text`, `wait_seconds`, and `screenshot_path`. The `compile()` method produces a fixed 5-step sequence: open → wait → assert_text → network → screenshot.
