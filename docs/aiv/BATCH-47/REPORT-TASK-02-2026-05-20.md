## Implementation Summary

### PlaywrightStealthBridge
- Wraps a Playwright CDP session for Chromium pages
- Implements full `StealthBridge` protocol: `cdp_send`, `inject_script_before_load`, `get_ax_tree`, `get_all_cookies`, `set_cookies`, `capture_screenshot_cdp`
- `inject_script_before_load` is a stub (wired in BATCH-49)

### PlaywrightPage
- Wraps a Playwright `Page` object to satisfy `EnginePage` protocol
- All 21 EnginePage members implemented
- CDP session created lazily via `_ensure_cdp()` for Chromium only
- Firefox/WebKit pages return `None` for `stealth_bridge` and `cdp`
- `scroll()` handles both locator-based element scroll and `mouse.wheel` viewport scroll
- `engine_page` property returns `self` for backward compat
- `raw_page` property returns underlying Playwright Page (deprecated)

### PlaywrightEngine
- Wraps Playwright library to satisfy `BrowserEngine` protocol
- Supports 3 browser types: `chromium`, `firefox`, `webkit`
- `start()` does lazy import of `playwright.async_api` (ImportError on missing install)
- `capabilities` varies by browser type:
  - **Chromium**: `cdp=True`, `stealth_inject_before=True`, `network_intercept=True`
  - **Firefox**: `cdp=False`, `bidi=True`, `stealth_inject_after=True`
  - **WebKit**: `cdp=False`, `bidi=False`, `stealth_inject_after=True`
- Async context manager (`async with`) supported
