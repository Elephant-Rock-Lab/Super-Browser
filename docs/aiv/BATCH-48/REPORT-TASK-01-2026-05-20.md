## Architecture Summary

### SeleniumEngine
- Manages WebDriver lifecycle (Chrome, Firefox, Safari)
- `start()` creates the appropriate WebDriver with options
- `new_page()` opens a new window/tab via JS, switches to it, wraps as `SeleniumPage`
- `stop()` calls `driver.quit()` via `asyncio.to_thread()`

### SeleniumPage (21/21 EnginePage members)
- **All** WebDriver calls wrapped in `asyncio.to_thread()` (sync→async bridge)
- `goto()` → `driver.get(url)`
- `title()` → `driver.title`
- `url` → `driver.current_url`
- `close()` → `driver.close()` (current window only)
- `content()` → `driver.page_source`
- `click()` → `find_element(By.CSS_SELECTOR).click()`
- `fill()` → `clear() + send_keys()`
- `select_option()` → `Select().select_by_value()`
- `hover()` → `ActionChains.move_to_element().perform()`
- `drag_and_drop()` → `ActionChains.drag_and_drop().perform()`
- `scroll()` → JS `window.scrollBy()` / `scrollIntoView()`
- `type_text()` → `ActionChains.send_keys().perform()`
- `press_key()` → `ActionChains.send_keys(Keys[key]).perform()`
- `set_input_files()` → `element.send_keys(path)`
- `evaluate()` → `driver.execute_script("return " + expr)`
- `screenshot()` → `driver.get_screenshot_as_png()`
- `route()` → **NotImplementedError** (Selenium can't intercept)
- `unroute_all()` → no-op
- `frame_locator()` → `driver.switch_to.frame(element)`
- `expect_download()` → **NotImplementedError**
- `stealth_bridge` → `SeleniumStealthBridge` (Chrome) or `None`

### SeleniumStealthBridge
- Uses `driver.execute_cdp_cmd()` for Chrome CDP access
- Implements full `StealthBridge` protocol
- Only created for Chrome browser type
