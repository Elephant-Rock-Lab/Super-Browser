## Implementation Summary

### Classes Implemented

1. **`WebSocketCDPSession`** — Adapter wrapping raw CDP websocket
   - `__init__(ws_url)` — stores URL, initializes pending futures dict and handler map
   - `async connect()` — establishes websocket via `websockets.connect()`, starts background `_reader_loop` task
   - `async send(method, params) -> dict` — sends JSON-RPC with incrementing message ID, awaits response future (30s timeout)
   - `async close()` — cancels reader task, closes websocket, resolves pending futures with error
   - `on(event, handler)` — registers event handlers (supports `*` wildcard for CDPBridge compatibility)
   - `@property id` — returns CDP session ID (CDPBridge.session_id compatibility)
   - `_reader_loop()` — background task: reads websocket, dispatches responses to pending futures, dispatches events to registered handlers

2. **`CDPDirectEngine`** — Implements `BrowserEngine` protocol
   - `__init__(endpoint="", config=None)` — stores endpoint and config
   - `async start(config)` — HTTP GET `/json` via aiohttp to discover targets, connects websocket, creates CDPBridge from adapter
   - `async stop()` — closes websocket session, clears references
   - `async new_page()` — creates CDP target via `Target.createTarget`, returns `CDPDirectPage`
   - `capabilities` — `cdp=True`, `stealth_inject_before=True`, `stealth_inject_after=True`, `network_intercept=True`, `name="cdp"`
   - `backend_name` → `"cdp"`

3. **`CDPDirectPage`** — Implements `EnginePage` protocol (all 21 members)
   - `goto()` → `Page.navigate` via CDPBridge
   - `title()` → `Runtime.evaluate("document.title")`
   - `url` (property) → stored from navigation
   - `close()` → `Target.closeTarget` + websocket close
   - `content()` → `Runtime.evaluate("document.documentElement.outerHTML")`
   - `click()` → JS `document.querySelector().click()`
   - `fill()` → JS `element.value=v; dispatchEvent(new Event('input'))`
   - `select_option()` → JS `element.value=v; dispatchEvent(new Event('change'))`
   - `hover()` → JS element center coords + `Input.dispatchMouseEvent mouseMoved`
   - `drag_and_drop()` → JS coords + `Input.dispatchMouseEvent` pressed/moved/released sequence
   - `scroll()` → JS `window.scrollBy()` or `element.scrollIntoView()`
   - `type_text()` → `CDPBridge.compositor_type()`
   - `press_key()` → `CDPBridge.compositor_key_press()`
   - `set_input_files()` → `raise NotImplementedError`
   - `evaluate()` → `CDPBridge.evaluate()`
   - `screenshot()` → `CDPBridge.capture_screenshot()` + base64 decode
   - `route()` → `Fetch.enable` + `on_event("Fetch.requestPaused", handler)`
   - `unroute_all()` → `Fetch.disable`
   - `frame_locator()` → `raise NotImplementedError`
   - `expect_download()` → `raise NotImplementedError`
   - `stealth_bridge` → `CDPDirectStealthBridge` (always available)

4. **`CDPDirectStealthBridge`** — Implements `StealthBridge` protocol
   - `cdp_send()` → delegates to `CDPBridge.send()`
   - `inject_script_before_load()` → stub (wired in BATCH-49)
   - `get_ax_tree()` → `Accessibility.getFullAXTree`
   - `get_all_cookies()` → `Network.getAllCookies`
   - `set_cookies()` → `Network.setCookies`
   - `capture_screenshot_cdp()` → `Page.captureScreenshot`
